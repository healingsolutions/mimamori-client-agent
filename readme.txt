サイトの初回診断、やさしい状態表示、無料のみまもりサポート開始、同意後の本部連携、診断データ出力を行うクライアント側プラグインです。

== Description ==

このプラグインは、お客様向けに難しい管理画面を見せず、次の一歩だけが分かる onboarding 体験を提供します。

- 初回は `最初に診断を始める` だけで開始
- 診断後は状態に応じて主な次の操作を 1 つだけ表示
- 必要に応じて無料のみまもりサポート開始申請へ進行
- 承認待ち、連携完了、ローカル利用中などの状態をやさしく案内
- 閉域環境では JSON ダウンロードを主導線として継続利用可能

== 安心の約束 ==

- 診断だけで更新、削除、設定変更を自動実行しません
- 画面上の申請・送信操作なしに本部へ診断データを送りません
- 承認前でも診断結果はこのサイト内に保存され、必要に応じてダウンロードできます
- 専門用語を主導線に出さず、次に押すボタンが分かる画面にしています
